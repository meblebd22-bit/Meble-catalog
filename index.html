🚀 ১ মিনিটে লাইভ শেয়ারেবল লিংক এবং ডিরেক্ট শিট সিঙ্ক চালু করুন:

এই ওয়েবসাইটে কিছু এডিট করে Sync দিলে যেন সরাসরি আপনার গুগল শিটে চলে যায় এবং আপনি যেকোনো কাস্টমারকে একটি লাইভ ওয়েবসাইট লিংক (URL) দিতে পারেন, তার জন্য:

  1. প্রথমে আপনার গুগল শিটটি খুলুন: Meble Bangladesh - Live Catalogue Sheet ↗
  2. শিটের উপরের মেনু থেকে Extensions → Apps Script-এ ক্লিক করুন।
  3. সেখানে থাকা কোড মুছে নিচের 📋 Copy Apps Script Code বাটনে চেপে কোডটি পেস্ট করে সেভ (💾) করুন।
  4. উপরে ডানদিকে Deploy → New deployment-এ যান, Select type → Web app নিন, Who has access: Anyone সিলেক্ট করে Deploy চাপুন।
  5. যে Web App URL (`https://script.google.com/macros/s/.../exec`) পাবেন, সেটি নিচের বক্সে পেস্ট করে Save & Sync চাপুন!
function doGet(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName('Catalogue') || SpreadsheetApp.getActiveSpreadsheet().getSheets()[0];
  return ContentService.createTextOutput(JSON.stringify({ok: true, rows: sheet.getDataRange().getValues()})).setMimeType(ContentService.MimeType.JSON);
}
function doPost(e) {
  var body = JSON.parse(e.postData.contents);
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName('Catalogue') || SpreadsheetApp.getActiveSpreadsheet().getSheets()[0];
  var data = sheet.getDataRange().getValues();
  var items = body.products || (body.product ? [body.product] : []);
  var idMap = {};
  for (var i = 0; i < data.length; i++) { idMap[String(data[i][0])] = i + 1; }
  items.forEach(function(p) {
    if (!p || p.id === undefined) return;
    var rowVals = [String(p.id), p.name || '', p.code || '', p.category || '', p.size || '', p.low === null || p.low === undefined ? '' : p.low, p.high === null || p.high === undefined ? '' : p.high];
    if (idMap[String(p.id)]) {
      sheet.getRange(idMap[String(p.id)], 1, 1, rowVals.length).setValues([rowVals]);
    } else {
      sheet.appendRow(rowVals);
    }
  });
  return ContentService.createTextOutput(JSON.stringify({ok: true, count: items.length})).setMimeType(ContentService.MimeType.JSON);
}
🐙 GitHub Pages / Cloudflare / Netlify দিয়ে ১ ক্লিকে লাইভ ওয়েবসাইট (Apps Script ছাড়াই!):

Apps Script-এ এরর আসলে সেটি বাদ দিয়ে সরাসরি GitHub Pages বা Cloudflare Pages ব্যবহার করতে পারেন:

  1. নিচের ⬇️ Download index.html (GitHub / Netlify Ready) বাটনে ক্লিক করে ফাইলটি ডাউনলোড করুন।
  2. আপনার গুগল শিটটি (Meble Live Sheet ↗) খুলে শুধু উপরের ডানদিকে Share → Anyone with the link (Viewer) করে দিন (কোনো Apps Script লাগবে না!)।
  3. এবার GitHub-এ একটি পাবলিক রিপোজিটরি খুলে `index.html` ফাইলটি আপলোড করে Settings → Pages → Branch: main চালু করে দিন (অথবা app.netlify.com/drop-এ ড্র্যাগ করুন)।
  4. আর ওয়েবসাইটের ভেতর থেকেই সরাসরি GitHub-এ অটো-সেভ করতে চাইলে নিচে আপনার GitHub Repo (`username/repo`) ও Token বসিয়ে দিন!
